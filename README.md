# Using Generative AI Tools - Boon or Bane

## Overview
   This repository stores the main files for the research project **"Using Generative AI Tools - Boon or Bane"**. The files are organised into folders for literature review, quantitative analysis, qualitative analysis, reports and drafts, and additional materials. This structure helps keep the research documents clear, easy to find, and suitable for team collaboration.
- `Literature_review`: contains literature review sources, such as journal articles and book chapters.

- `additional_materials`: contains supporting files, such as participant information sheets and presentation media.

- `qualitative_analysis`: contains qualitative research files, such as consent forms, interview transcripts, and insights reports.

- `quantitative_analysis`: contains quantitative research files, such as analysis scripts, cleaned survey data, and survey analysis reports.

- `reports_and_drafts`: contains writing outputs, such as research proposal drafts, conference paper drafts, and the final report.
